# CYMONIA v1 — Historical Prototype

CYMONIA v1 is retained as a **historical prototype** of the project before the Sovereign World architecture.

v1 demonstrated deterministic economic agents, policy machinery, a published dashboard, a causal event log and the first live-world renderer. Those components are useful project history, but their scripted social assumptions violate the v2 sovereignty contract.

The v2 installer preserves the previous production `site/index.html` as `archive/v1/index-v1.html` on first application and preserves the previous scheduled economy workflow as `archive/v1/economy-v1.yml` when present.

Nothing in this archive is authoritative for the v2 canonical world. GitHub Actions must not advance v2 world time.
