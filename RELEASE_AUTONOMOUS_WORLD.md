# CYMONIA Autonomous World Alpha

This release turns CYMONIA from a playable observatory into an autonomous civilization prototype.

## Included

- Permanent Genesis 100.
- Human-linked Citizen per GitHub identity.
- Dedicated Personal Agent with versioned CymScript.
- MANUAL / ADVISOR / AUTONOMOUS owner modes and risk guardrails.
- Endogenous needs and citizen-created innovation definitions.
- Companies, employment, salaries, tax, consumption and construction.
- Central Bank, Government, simulated crime, Police and Justice events.
- D1 persistence and causal World Event log.
- Public World/News/WHY APIs.
- Isometric RTS World UI with pan, zoom, minimap, Follow Citizen, inspector and World News.
- Deterministic static replay for GitHub Pages.
- Zero-mandatory-cost scheduled D1 clock through GitHub Actions.

## Deliberate boundaries

This is a simulation, not a cryptocurrency or financial product. Crime is abstract in-world behavior. AI cannot directly mint, settle, seize property or rewrite the Constitution. CymScript cannot execute arbitrary code.
