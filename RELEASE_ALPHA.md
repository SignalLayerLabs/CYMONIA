# CYMONIA Human–AI Economy Alpha

This package extends the playable Astra-era CYMONIA repository with the first participatory economic loop.

North Star: **Can an economy learn how to improve itself?**

Implemented loop: **Detect → Fund → Work → Prove → Settle → Learn**.

Highlights:
- GitHub identity with one-time 20 bCYM onboarding balance.
- Separate earned CYM and Economic Reputation.
- Economic Contracts restricted to measurable CYMONIA improvements.
- Contribution Treasury + escrow + journaled/idempotent settlement.
- Numeric Proof of Economic Contribution with frozen baseline and threshold.
- AI proposal brain behind a replaceable Workers AI binding; AI cannot mint/fund/settle.
- AI Companies and Economic Stakes at internal book value.
- AI Companies can claim contracts and grow treasury through accepted PoEC, changing stake book value.
- PoEC outcomes are retained as economic memory and exposed to future AI proposals.
- Cloudflare Pages Functions + D1 + Workers AI deployment path designed for the free tier.

Read `docs/deployment-cloudflare.md` before enabling live participation.
